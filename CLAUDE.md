# Working in this repository

Orientation for whoever picks this up cold — human or agent: what lives where,
what is generated and what is written by hand, and what has to be true before a
change is pushed.

## What this is

A pnpm + Turborepo monorepo for the Age of Weapons 5 (a Dota 2 custom game) wiki
and its tools. The game data is committed here; nothing under version control is
read from the game at runtime.

| Where | What |
| --- | --- |
| `packages/aow5-shared` | The extracted game data, the icons, the id tables, the wiki logic (renderers, SEO, share-link codec) and their tests. Consumed as TypeScript source, not as a build output. |
| `apps/webapp` | The site: build guides, the wiki, the tracker download page. Vite + React. |
| `apps/api` | The builds API — NestJS over SQLite through drizzle. `core/` is the domain and must not import Nest. |
| `apps/tracker` | The Electron overlay. It ships on its own tag (`tracker-v*`), and only *packaging* it needs Windows. |
| `parser/` | The extraction pipeline. Deliberately **not** a workspace member: it only runs on a machine with the game installed, and everything it writes is committed under `packages/aow5-shared`. |
| `infra/` | Docker, Caddy and the deploy scripts. Deploys run from GitHub Actions ("Deploy site"), never from a laptop. |

## Generated, and hand-edited

**Generated by `parser/` — do not edit by hand.** The next run overwrites these,
and the id tables are worse than that:

- `packages/aow5-shared/public/data/**` (including `wiki/`) and `public/icons/**`
- `packages/aow5-shared/data/{id,ability,map}-table.json` — **append-only**:
  existing entries are referenced by index from elsewhere, so their order is
  load-bearing and an entry is never removed or reordered.

A guard hook (`.claude/hooks/guard-generated.mjs`) refuses `Edit`, `Write` and
`NotebookEdit` on those paths and says where the change belongs instead. For a
deliberate exception, set `AOW5_ALLOW_GENERATED_EDIT=1` for the session.

**Written by hand, and validated by tests:**

- `packages/aow5-shared/content/faq.{ru,en,zh}.json`, `patchnotes.{ru,en,zh}.json`,
  `guild-orders.json`
- `packages/aow5-shared/data/name-overrides.json` — names the pak does not carry
- `parser/config/aow5.config.json` (expectations, rosters, known issues) and
  `parser/tools/golden.json`

The pipeline is deterministic: re-running it must leave the working tree clean —
`parser/tools/lib/writeJson.ts` sorts keys and writes LF. A diff after a run means
something is not sorted, or an expectation in the config moved.

## Translations

Content that ships in three languages must stay in step: the same sections,
sub-tabs, block shapes and patchnote versions in all of them. The text differs,
the structure does not — that is what `packages/aow5-shared/src/wiki/content-i18n.test.ts`
enforces. When one language gains a section, all three gain it in the same commit.

## Checks

Exactly what CI runs, in order:

```
pnpm install --frozen-lockfile
pnpm check-types
pnpm test
pnpm test:parser   # parser/ is outside the workspace, so Turborepo never reaches it
pnpm build
pnpm --filter aow5-utils-api smoke
```

Run the first five before pushing. TypeScript is strict everywhere (`strict`,
`noUnusedLocals`, `noUncheckedIndexedAccess`, `erasableSyntaxOnly`) — except in
`apps/api`, where Nest's decorators need `experimentalDecorators`.

## Pull requests

Branch off `master`, keep a PR to one coherent change, and write the feature
description the app's `CONTRIBUTING.md` asks for: what changed, what it does to
data other people already depend on (a shared build link, a stored build, an
existing tracker `config.json`), and what was knowingly left out.

## Secrets

Real values never enter the repository: `infra/*.example` are templates, the real
files are gitignored and live on the server (`/srv/aow5/.env`).
`apps/api/src/config.ts` is the single place the API reads environment variables —
a new variable means a line there, not a `process.env` somewhere else.

## Where the data comes from

`parser/tools/run-all.ts` drives the steps (`01` index the pak, `02` extract raw,
`03`–`04d` build the tables, `05`–`06` icons, `07` emit, `08a`–`08e` the wiki
files, including the achievements the calculator reads). The pak path comes from
`AOW5_VPK` or `parser/config/aow5.config.json`;
the `expected` block in that config is a pin guard that warns rather than fails
when a new build moves the numbers. `parser/tools/verify.ts` compares the emitted
files against `golden.json`.
